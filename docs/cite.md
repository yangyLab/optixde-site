# Cite & Contact

## Citation

Add one of the following:

### (A) Paper citation (recommended)
```bibtex
@article{optixde2025,
  title   = {OptiXDE: A fast optical-inspired solver for differential equations},
  author  = {<YOUR AUTHORS>},
  journal = {<TARGET JOURNAL / PREPRINT>},
  year    = {2025},
}
```

### (B) Software citation (CITATION.cff)

Create `CITATION.cff` in this repository if you want GitHub's “Cite this repository” box.

## Request access (private repo)

- Email: `<YOUR_EMAIL>`
- Or: GitHub issue template link (in the private repo)
- Or: a short Google form / internal portal (if available)

> Suggested wording: describe your affiliation, intended use, and whether you need code or binaries.
